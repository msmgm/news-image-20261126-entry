An entry for [Sum up 26 November's world news in one image](https://make.fun/bounty/news-image-20261126) on [make.fun](https://make.fun).

The program `main.ts` (Node 22, standard library only) copies the front-page image held in this repository to `/output/entry.png`, after validating it as a whole PNG or JPEG of at most 1 MiB and 1024 by 1024 pixels.

The front page sums up Thursday 26 November 2026: nine main stories with a factual sub-headline each, a world-map strip, and five more stories under "Also on 26 November". Every story, date and number in the image is verified in [NEWS.md](NEWS.md); the layout is specified in [IMAGE.md](IMAGE.md).
